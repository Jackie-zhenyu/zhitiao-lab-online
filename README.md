## Windows 安装与启动

从项目根目录运行（PowerShell 或 cmd 均可，无需激活虚拟环境或更改脚本执行策略）：

```powershell
.\scripts\install.cmd
.\scripts\start.cmd
```

本机已有独立环境，可直接执行 `start.cmd`。新电脑先安装 Python 3.12；安装器优先检查已有 `.venv`，否则用 `py -3.12` 创建，不覆盖损坏/不兼容环境。找不到 Python 启动器时，执行 `.\scripts\install.cmd "C:\实际路径\Python312\python.exe"` 指定已安装的 Python 3.12。安装失败会返回非零状态，不能继续当作安装成功。

浏览器打开 <http://127.0.0.1:8501>。终端按 `Ctrl+C` 停止服务。端口被已运行的本项目占用时，可直接访问；另开服务用 `.\scripts\start.cmd --port 8502`。只检查环境用 `.\scripts\start.cmd --check-only`。等价核心启动命令是 `.\.venv\Scripts\python.exe -m streamlit run app.py`，项目配置默认只监听本机。

打开后进入“实验分析”。在左侧“数据入口”选择“上传 CSV”或“加载示例”。侧栏“实验对比”使用已保存的确认快照；“报告预览”可生成、核对并下载三种格式。左侧集中字段/单位、区间和配置；主区“质量、指标与曲线”“异常证据”分开，顶端另有“AI 分析”区域，不挤压图表。页面切换保留当前会话内容；新会话或服务重启后可上传已下载的项目包恢复。修改代码后建议完整停止并重启服务，避免开发热重载混用旧类实例。

## 保存项目，下次继续

左侧底部展开“项目 · 保存与恢复”，填写名称，点击“生成项目包（含原始 CSV）”，再下载 `.labproj` 文件。下次启动后选择此文件→校验项目包→核对摘要数量并确认替换→恢复项目。历史快照可载入为工作实验或移除；也可显式清空当前会话。不会自动保存，关机前务必完成下载。

项目包包含完整原始CSV，未加密；默认包上限128MiB、去重原始文件64MiB、单CSV20MiB/200000行、8份历史快照。恢复会重新核验配置和计算；AI授权与活动聊天证据不恢复。历史报告只归档JSON，新报告从报告预览重新生成。详见 [项目格式与使用边界](docs/PROJECTS.md)。

## 报告导出与手动验收

1. 从左侧加载“一阶解析阶跃响应”，确认字段、单位，再核对并确认单次阶跃；也可以完成下文的闭环PI A/B流程。
2. 进入左侧“报告预览”，选择“当前实验”或“已确认A/B对比及两侧实验”，填写项目名、实验名、备注。设备/负载不清楚就保持未知。
3. 点击“生成 / 更新报告快照”，核对主区指标表、结果ID与配置ID；展开结构化快照检查区间、映射、阈值、初值、版本、来源和完整质量问题。页面与三种文件使用同一冻结结果，HTML区分程序计算与AI解释。
4. 下载HTML、JSON、CSV。HTML在本机浏览器打开后应能缩放、悬停、复位，不依赖CDN；JSON保留精度与null，CSV使用UTF-8 BOM。没有AI结果应显示“AI 未参与”，不会自动调用模型。未确认阶跃的响应指标明确未计算；仅有质量问题也可导出。
5. 返回实验页修改末段比例或选段，再到报告页，应保留旧快照并提示重新生成。生成新报告后核对新配置及对应结果，旧下载文件保持不变。
6. 在报告备注填写 `<script>alert(1)</script>` 再生成，报告只显示该文本，不执行脚本或弹窗。不要用真实密钥作为测试文本。用户名称不会变成下载路径，CSV的文本公式前缀会加单引号，合法负数值仍保持负数。
7. 用窄窗口打开页面与HTML，侧栏可折叠，控件应换行、表格可横向滚动；主图和AI分别查看。断网验收时先下载HTML，再关闭网络并重新打开，图表仍应交互。

报告每条曲线最多5000个显示点，可能漏掉尖峰，指标仍使用完整原始有效时间戳。A/B报告分别标明原确认区间和共同观察区间。JSON结构超过32 MiB时拒绝生成，不静默省略证据。报告不嵌入整份原始CSV，仍包含必要的显示曲线数据。完整约定见 [报告格式](docs/REPORT_FORMAT.md)。

本机历史验收产物在 `outputs/智调Lab-闭环AB示例.html`、同名JSON/CSV，均由本地页面流程和正式导出代码生成，标注闭环仿真、非实测、AI未参与。`outputs/`被忽略，不随源码交付；新环境请按上述流程生成下载。最终实际验收见 [开发进度](docs/PROGRESS.md)。

## AI配置与追问验收

顶端“AI 分析”标签提供“AI 分析 · 依据实际工具结果追问”。选当前工作实验或确认快照作为A；对比时选择已保存的A/B单阶跃快照，核对AI区共同观察时长和本轮条件。没有密钥时不产生模型回复。

仅在需要AI时，将 `.env.example` 复制为未被Git跟踪的本地 `.env`，填写 `LLM_PROVIDER`、`LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY`，然后重启。不要把真实Key发到聊天中。完整地域、模型依据、预算和安装版本见 [通义千问配置](docs/LLM_CONFIGURATION.md)。

1. 输入“分析实验A”，先查看目的地址、实验摘要和历史范围；勾选本轮授权后点击“授权并发送本轮请求”。勾选本身不会发送。
2. 展开实际模型/工具记录、测得事实和证据引用。数字由程序从本轮result_id/指标键渲染，模型只能选择证据和受控解释类别，不能自行填写数值。
3. 追问“只看其中2～5秒”，再次授权，确认新的analyze_run工具调用、区间和result_id；新范围缺完整阶跃时只算跟踪指标，不沿用旧响应值。
4. 选择两份已确认快照，问“与实验B比较超调和响应时间”。应执行compare_runs，分别从原始时间戳计算；零分母的百分比不可用，不给综合评分。
5. 修改单位、配置、选段或AI区条件后，旧证据和授权失效。非法引用、格式错误、超时或循环明确降级/停止，不能补成假答案。

默认不发送整份CSV、文件名、备注、任意列名、条件原文或本地路径；发送必要指标、规则/事件摘要、来源标识、有限问题历史和配置。问题正文会发送，请只填写希望授权的问题。第一版解释采用受控模板。已在公开 PI A 闭环仿真数据0–21秒上实际完成 `profile_data`、`analyze_run`、`detect_events`，首次最终证据校验不通过，经一次有限纠正后成功；不能据单个案例估计结构化答案服从率或普遍问答质量。上述第3、4步的真实多轮与 AI 对比仍须分别授权验收。执行契约与自动/手动验收见 [Agent说明](docs/AGENT.md)。

## 现象证据与规则核对

确认字段和单位后，切到主区“异常证据”，查看“异常现象与证据”。它对整份日志中各个连续有效片段检查稳定目标附近的持续波动、控制输出持续接近已确认限值、测量变化，并保留全文件的数据记录问题。规则不会跨缺失行、时间倒退或异常间隔拼接样本。

- 展开“现象规则参数”，核对当前值、默认值及来源。波动默认窗口 2 s、死区外交替至少 4 次、峰峰差至少 0.05、死区 0.01、平均误差带 0.2、死区外时间占比至少 25%；幅值阈值使用已确认的物理单位，须按对象调整。
- 控制近限规则必须有 `control`，并填写上下限、勾选“我已核对控制输出单位及上下限”。闭环示例预填的 `[-2.5,2.5]` 也需要确认。默认接近带为限值跨度的 2%，连续命中样本首尾至少 0.5 s；现象不能据此确认为积分饱和。
- 物理变化率上限可以留空。填写且确认适用于对象/单位后才使用该物理上限；未确认时只产生“统计突变候选”，不认定传感器故障。统计规则默认使用中位数加 6 倍缩放 MAD，并要求跳变量至少 0.05。
- 每张卡片区分“检测到的现象”与“尚不能确定的原因”，可展开规则、阈值、观测量、来源定位和限制。点击“聚焦这条证据”只改变独立证据图的显示范围，不改变性能指标分析区间；时间不可靠的数据记录问题按原始行聚焦。
- 改动规则会撤销旧证据与聚焦。时间占比按左端样本状态乘实际相邻时间差估计，持续时间按原始时间差计算。没有规则事件不证明系统完全正常。

完整窗口、阈值和证据边界见 [现象证据规则](docs/EVIDENCE.md)。默认 PI A/B 示例在当前规则下未检出事件；可加载“数据质量问题”检查记录证据卡及原始行聚焦。

## 闭环 PI A/B 手动验收

两份示例均标注 **“闭环仿真数据，非实测”**。共用一阶对象 `dy/dt=(-y+u)/tau`、`tau=1 s`、初值 0、采样周期 0.02 s、记录 0–21 s、1 s 时目标从 0 到 1、限幅 `[-2.5,2.5]` 和无噪声条件。A 使用 `kp=0.6,ki=0.4`，B 使用 `kp=2,ki=2`；只改 PI 参数，没有人工修改曲线。PI 先更新积分再输出，对象按精确零阶保持更新，无抗积分饱和，详见 [闭环示例说明](examples/CLOSED_LOOP.md)。

1. 在“实验分析”选择“加载示例” → “闭环 PI A”，点击“一键加载示例”。核对来源标签、1051 行及原文件摘要。
2. 分别核对 `time/target/actual/control/p_term/i_term` 映射。时间单位为 `s`，物理量为“响应量”，目标/实测及三项可选信号的单位均为 `1`。勾选单位一致声明，点击“确认字段和单位，检查数据”。完整连续区间应为原始行 1–1051、0–21 s。
3. 保持既有默认指标参数，在“单次阶跃确认”核对候选 `t0=1 s,r0=0,r1=1`。基线应为数据行 26–50、0.5–0.98 s，共 25 点，`y0=0`。核对声明后点击“确认单次阶跃并计算响应指标”。
4. 展开“保存当前实验及确认阶跃，用于 A/B 对比”，填写名称并点击“保存已确认实验”。这是当前会话的独立快照，包含原始数据、质量、配置和已确认阶跃；最多保留 8 份。
5. 加载“闭环 PI B”，重新完成它自己的映射、单位、阶跃及基线确认，然后以另一名称保存。加载 B 不会改写已保存的 A。
6. 进入“实验对比”，分别选择 A/B 快照。核对两侧被控对象、负载、采样、环境及 PI 参数记录；未知条件留空。示例条件由清单提供，控制器参数不同是允许的比较条件，不能据此直接作 PID 因果归因。
7. 两侧可用阶跃后时长均为 20 s。将“共同请求观察时长”保持为 20，勾选共同窗口确认，再点击“计算 A/B 对比”。应显示各侧原始行 51–1051、绝对时间 1–21 s、相对时间 0–20 s；目标/实测和误差按各自 `t−t0` 对齐。
8. 核对七项指标、差值、百分比及逐项状态。差值为 `B−A`，百分比为 `100*(B−A)/abs(A)`，不能把百分比称为提升评分。超调均为 0 时，差值为 0，百分比为空并说明零分母。

还可以进行以下边界验收：

- **自比**：A/B 选择同一快照并确认窗口；可用指标的差值应为真实 0，A 值为 0 的百分比保持空值。不可用指标不补 0。
- **窗口变化**：将共同请求时长改为 10 s，旧结果应立即撤销。再次核对、确认并计算；不超出任一已确认段，不跨下一阶跃或质量断点。不同采样周期的实际末点可能早于请求截止点，页面会显示真实窗口和差异警告，不插入对齐计算点。
- **单位或评价口径不一致**：用单位声明不同的测试快照比较，页面应保留各侧值，差值与百分比为空，图形按各自单位分开显示。改变指标参数后须重新确认并另存快照；评价口径不同时也拒绝差值，不覆盖另一侧设置或偷偷换算单位。
- **条件变化**：把一侧负载留空或填写不同记录，旧结果应撤销。重新计算后应有未知/不一致警告，只作有条件的数值描述，不宣布绝对优胜。

## 沿用的第三阶段指标与手动验收

**响应指标采用“相对于目标值的归一化约定”，不是按实测稳态值归一化的标准 stepinfo。** 该声明保存在页面、完整指标结果和导出报告中，报告直接保留既有数值与阈值。

记 e=target−actual，分析区间为连续 `[ta,tb]`，响应 q=(actual−y0)/(r1−y0)，A=abs(r1−y0)。

| 指标 | 本版定义 |
| --- | --- |
| 时间加权 RMSE | sqrt(∫e²dt/(tb−ta))，按实际时间对平方误差样本梯形积分 |
| IAE | ∫abs(e)dt，按实际时间对绝对误差样本梯形积分 |
| 最大绝对误差 | 全量选段采样点中 max(abs(e)) |
| 末段平均偏差 | 默认最后10%时间窗口内的时间加权平均 e；不能称为稳态误差 |
| 目标归一化上升时间 | q 首次从0.1达到0.9的时间差；相邻有效采样点线性插值 |
| 目标归一化超调量 | max(0,max(q)−1)×100% |
| 目标调节时间 | 最终连续进入 abs(actual−r1)≤max(0.02A,绝对容差) 的时刻减t0；后续观察默认至少0.5s |

这些默认阈值、末段比例和基线条件均可配置并保存。调节时间只表示**在本次观测区间内满足**，不保证未来；最大误差与超调不推断漏采的峰值。详细适用性、积分和交点口径见 `docs/METRICS.md`。

1. 加载“一阶解析阶跃响应”，核对字段/单位并确认；出现四项一般跟踪指标。它们使用上方完整选段，不用普通样本均值替代时间加权结果。
2. 查看“单次阶跃确认”：默认候选 t0=1s、r0=0、r1=1。有效基线应为数据行11–20（0.5–0.95s），y0=0；勾选核对声明，点击“确认单次阶跃并计算响应指标”。
3. 示例时间常数是0.7s，所以上升时间应约1.538s、目标调节时间约2.739s（均相对t0），超调0%。这与测试使用的时间常数1s基准不同。
4. 展开每个指标的解释，核对定义、状态、实际区间、基线、阈值、观察时长、原文件摘要及版本。目标/实测曲线应出现上下阈值、目标误差带及相关时刻。
5. 将阶跃观察截止数据行改为40并重新确认，记录过短，响应上升/调节应返回无数值及明确原因。改变参数、候选、手工输入或分析区间后，旧响应结果立即撤销。
6. 把总选段起始行设为21（去掉基线），切换“手动指定”，填t0=1、r0=0、r1=1；默认无基线不能计算。明确选择“手动提供 y0”，填写0并核对确认后才计算，来源标记为用户提供。
7. 多阶跃文件应逐个选择候选，观察区间在下一阶跃前截止；持续变化目标或静态目标不能自动当成一个阶跃。问题文件须先选连续有效片段，不跨断点计算。

3. 在图表上悬停读数、滚轮/框选缩放、使用 Reset axes 复位。核对实际使用区间为数据行 1–121、0–6 s。
4. 加载“非等间隔采样”并重新确认；默认规则会标记较长间隔并阻止直接画整段。选择一个连续有效区间后出现该区间曲线。

6. 改动映射、时间单位、物理单位或间隔阈值，旧质量结果和曲线应立即消失，必须再次确认。切到“实验对比”再返回，当前会话的数据和已确认配置应保留。

8. 用相同文件名上传内容不同的 CSV，展开原始文件摘要检查 SHA-256 改变，旧确认撤销。展开导入设置，把行数上限改为 100 再载入 121 行示例，应拒绝导入而不是悄悄截断。

## CSV 与质量规则

- 默认单文件 **20 MiB / 200000 数据记录**，可在导入设置修改（界面范围 1–200 MiB、1–2000000 行；解析 API 可配置正整数限制）。上传控件也同步设置文件上限。解析分块最多读取字节上限加一个探测字节，逐条 CSV 记录检查行数。
- 自动编码只接受严格 UTF-8 / UTF-8 BOM；手选支持 UTF-8、UTF-8 BOM、GB18030、UTF-16、CP1252。分隔符为逗号、分号、Tab；自动识别保守，歧义请手选，不忽略坏字节或坏行。小数使用点号；不擅自按地区换算小数逗号。
- 必须映射 time / target / actual，可选 control / p_term / i_term / d_term；推荐并不代表确认。原始列名精确保留，带空格的列名不会被合并。
- 时间只做用户指定的 ms → s（除以 1000）或 s 保持；目标和实测使用用户确认的共同单位，不猜编码器比例。误差为 target − actual。
- 映射字段检查非数值、缺失、无穷，以及重复时间、倒退、疑似重置和采样间隔异常。默认间隔规则为正相邻时间差中位数的 `[0.5, 2.0]` 倍；规则命中不等于设备故障。
- 不排序、删除、填补、平滑或插值。阻断问题必须明确选取至少 2 行的连续有效片段；保留整份原始字节、SHA-256、原始字符串及行号、单位、配置和转换记录。
- 图表等索引抽点仅改变显示副本，默认每条最多 5000 点，可能遗漏尖峰；质量检查仍使用全部数据。缩放不会动态重采样，可调高显示点数上限（最多 200000）。

位置、时长、间隔统计、缺失值和疑似重置的具体口径见 [解析规则](docs/CSV_IMPORT.md) 与 [质量规则](docs/QUALITY.md)。

## Linux/macOS 命令与依赖约束

实际验证环境为 **Python 3.12.14、Windows x64**，全部依赖位于项目 `.venv`，未修改系统 Python。锁文件的 57 个包均为实际版本；`requirements.txt` 固定直接依赖，`requirements-dev.txt` 固定 pytest，复现时统一安装完整 `requirements.lock.txt`，不自行升级。

Linux/macOS 安装 Python 3.12 后，从项目根目录执行：

```bash
python3.12 scripts/manage.py install
.venv/bin/python -m pytest -q
.venv/bin/python scripts/manage.py start
```

上述安装器创建/检查项目 `.venv`，只安装锁定二进制包；启动器检查实际版本后执行 `python -m streamlit run app.py` 并绑定 `127.0.0.1`。Linux/macOS 尚未实机验收，架构缺少预编译 wheel 时会明确失败，不偷偷放宽版本或系统安装。普通手动环境命令为 `python3.12 -m venv .venv`、`.venv/bin/python -m pip install -r requirements.lock.txt`，仅在 `.venv` 不存在时创建。

当前 NumPy / SciPy 锁定版本需要 Python ≥ 3.12；交付脚本限定已验证的 3.12 系列。Python 3.11、3.13/3.14 的环境不属于本次可复现交付范围。安装需能访问包源或已有 wheel 缓存；断网环境应预先准备同平台的完整 wheel 包，不能把失败安装记录为成功。

第五阶段新增OpenAI兼容SDK、httpx和python-dotenv，已安装在项目虚拟环境；实际版本已更新到锁定快照。`.env`仅用于可选AI，本地分析不必复制或填写。Streamlit默认只监听 `127.0.0.1`，关闭使用统计，不涉及公网部署。

## 会话、清除与常见故障

- 未下载的原始字节、分析结果、最多8份A/B快照、聊天和报告仅在当前 Streamlit 会话内存中；没有数据库、账户或自动磁盘保存。刷新可能新建会话；关机或会话回收前请下载项目包和报告。包可恢复实验，活动聊天和授权不恢复。
- 上传控件移除文件，或回到上传页使用“清除保留的上传数据”，会撤销当前工作文件及结果。切换文件或示例也会撤销工作结果。已另存的A/B快照是独立副本，需在对比页分别删除；移除工作文件不会删除这些快照或本机已下载文件。
- 清空单个会话：项目面板勾选声明并点击“清空当前会话”；其他会话和下载文件不受影响。停止服务并重新启动则会清除该进程中的所有会话。聊天不恢复。
- “AI 未配置”：本地功能正常。按模型配置文档在本机填写服务端配置并重启；不要在聊天中提供密钥。真实网络/模型不可用时显示限制，不伪造回复。
- 找不到Python或WindowsApps别名失效：使用 `install.cmd` 的明确 Python 3.12 路径参数。无需执行 `Set-ExecutionPolicy` 或激活脚本。
- 安装失败：阅读 pip 的网络、权限或 wheel 错误，检查网络/包源和 Python 版本；不要把“已存在一些包”当成完整安装。`start.cmd --check-only` 会列出缺失或版本不匹配的包。
- 端口占用：使用现有服务，或用 `--port 8502`。页面打不开先核对终端错误与地址，不需要公网端口转发。
- 修改代码后出现旧 Pydantic 类、旧样式或报告一致性拒绝：完整停止并重启，再重新加载/确认数据。开发热重载不保证旧会话对象兼容；不要取消一致性校验来绕过。
- CSV拒绝导入：核对编码、分隔符、读取上限和必需字段；有阻断问题先明确选择连续有效区间。单位变化后需要重新确认字段，物理变化率/控制限幅也须重新核对。
- 报告显示旧快照：返回报告页点击“生成 / 更新报告快照”。旧下载文件和旧冻结报告保持原配置；它们不会自动变为当前新结果。
- 本机HTML断网重开、Linux/macOS和Docker运行仍需按验收清单手动确认；不要将生成Dockerfile等同于容器已运行。
