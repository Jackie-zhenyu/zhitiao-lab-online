# 智调 Lab · 复赛演示分镜与旁白

本版补入 2026-09-06 获用户授权的真实 Qwen 单实验联调。使用实际网页截图、字幕和本机中文合成旁白，是**经剪辑的截图定格演示，不是连续录屏**。不得将示意图、离线模型替身或预期动作冒充真实运行。最终以媒体探测出的实际时长为准，输出 MP4，少于 5 分钟、200 MB。

## 本版素材与真实验证范围

- 公开一阶解析示例、问题示例均为“解析函数合成数据”；PI A/B 为“闭环仿真数据，非实测”。不展示私人文件、密钥、系统日志或未经确认的参赛身份。
- 导入、字段/单位确认、阶跃、质量、事件聚焦、共同 20 s A/B 对比、报告与项目包截图来自实际页面操作。多会话素材经过剪辑；每张图的来源与摘要由视频构建记录保留。
- AI 真实联调只涉及用户已授权的问题“分析实验A”，公开 PI A 的 0～21 s 区间。只发送问题、必要配置与分析摘要，未发送整份 CSV、文件名或备注。
- 本轮实际向模型发出 3 次请求；模型选择 `profile_data`、`analyze_run`、`detect_events`，各执行 1 次。第 2 次模型回复未通过证据校验，经 1 次有限纠正后形成通过校验的回复。视频保留这项限制和真实拦截记录。
- 仅验证一个单实验问题；**没有真实验证修改区间追问或模型触发 `compare_runs`**。不得以本轮成功扩写成完整多轮或 A/B Agent 联调。更早的认证失败与受控失败历史保留在联调验收说明中。
- 真实 API 记录独立于离线 pytest 数量；本地指标模块和口径不因本次媒体更新而改变。具体依据见 `docs/acceptance/live-ai-summary.json`。

## AI 片段的正式旁白

> 用户授权分析实验甲，范围为零到二十一秒。只发送必要配置与摘要，不发送整份日志、文件名或备注。
>
> 真实模型选择数据概览、性能分析和现象检测，三个工具各执行一次。数值仍由本地程序计算。
>
> 程序把结构化结果返回模型，再校验引用。这里展示本轮测得事实，数值、区间和来源都能展开核对。
>
> 模型第二次回复被证据校验拒绝，一次有限纠正后通过。实际共发出三次模型请求，拦截记录保留。
>
> 本次只验证单实验问题。修改区间的追问，以及由模型触发的实验对比，还没有完成真实联调。

机制示意旁白明确说明“这张图说明实现机制，不是调用录像”。不能剪成一次请求始终成功，不能用旧 A/B 数值画面声称模型本轮调用了对比工具。

## 数值与报告口径

- 解析示例时间常数为 0.7 s，不能配上独立测试基准时间常数 1 s 的理论数值。响应采用“相对于目标值的归一化约定”，不是标准 `stepinfo`；调节只表示本次观测区间内满足。
- 视频 A/B 两侧结果来自共同 20 s 观察区间，按各自 `t0` 对齐；本次真实 AI 单实验区间为 0～21 s。两种范围的跟踪指标不同，不得混用。
- 该 A/B 条件下 B 的响应时间和跟踪误差更小，两侧超调均为 0，超调变化百分比不计算。不自动宣布全面更好，不把仿真差异直接当成真实设备改善。
- 视频原报告截图展示无 AI 的本地 A/B 快照，与后续真实 AI 单实验回复属于不同结果。无 AI 时导出正常，并明确标注未参与；不暗示同一报告已包含后续回复。
- 应用方案 PDF 是独立参赛文档，应用本身导出 HTML/JSON/指标 CSV。没有实际物理断网重开报告的验证时，不宣称已经完成该人工验收。

## 构建和验收

使用与应用依赖分离的本地媒体环境，不读取 `.env`，不发出模型或其他网络请求：

```powershell
.\work\submission-tools\.venv\Scripts\python.exe scripts\build_submission_video.py --work-dir work/submission-video-live --output work/submission-video-live/智调Lab-演示视频.mp4
```

脚本默认拒绝覆盖已有交付文件。旧 MP4 保留到 `work/submission-before-live/` 后，新版本先输出到独立工作目录，再由交付流程核对后替换固定成品。截图只读；可显示局部，但不得篡改或重绘真实结果。

1. 读取实际容器信息，核对 1280×720、24 fps、H.264/yuv420p、AAC、时长与大小；全片音视频解码必须成功，验证 MP4 fast-start 顺序。
2. 抽取各主要片段成片帧，核对中文、字幕分行、来源标签、真实工具记录与纠正说明。截图可能因浏览器缩放较小；不以虚构文字替换真实界面。
3. 本地合成语音检查各段非静音、音频幅度；这不等于人工试听。正式提交前仍需用户播放一次，检查听感、平台转码与观看体验。
4. 密钥不进入视频或源码；真实联调通过只表示本次公开示例和当前模型接口工作，不能外推为真实设备、全部追问、多用户负载或网络持续可用。
5. 最终媒体规格与 SHA-256 记录在构建目录的 `video-verification.json`，交付清单须引用新成品，不沿用旧 MP4 的大小、时长或摘要。

原始提交截图要求应用方案 PDF ≤20 页/200 MB、演示 MP4 ≤5 分钟/200 MB，并提供可运行程序链接或源码；未提供完整赛事评分细则，不假定额外评分权重。
