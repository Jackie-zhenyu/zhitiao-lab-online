# A/B 实验对比 · 第四阶段

沿用 `docs/METRICS.md` 和 `control-metrics-v3.0` 全部计算口径，不新增综合评分，不自动宣布绝对优胜，不作PID根因归因。

## 确认与窗口

先在“实验分析”分别导入、确认映射与单位、确认每个实验的单次阶跃，将完整原始数据/质量/配置/阶跃快照保存到**当前会话**，再在对比页选择A/B。快照为独立副本，之后更改工作实验不悄悄修改已确认快照。每个快照有独立来源摘要和配置标识。

按各自 `t-t0` 对齐，正向与负向相同，不以文件首行为零。默认共同请求观察时长为两份已确认阶跃可用时长的较小者，用户须明确确认，可以缩短但不能超出任一确认段或跨下一阶跃/断点。

每侧保留阶跃基线供原有响应函数使用，截取原始样本至 `t<=t0+共同请求时长`。一般跟踪指标只使用 `t>=t0` 的原始样本；响应指标按原有t0交点口径计算。**不为对齐或共同截止时间插入指标计算点**。非等间隔或不同采样周期时，两侧实际首尾点可能不完全相同，必须显示实际原始行、绝对/相对时间和剩余时长偏差并给描述性警告；不能声称完全相同的有效采样窗口。绘图使用各侧原始时间减t0，可分别显示抽点，不修改计算数据。

## 可比性

检查物理量名称、单位、r0/r1与初始y0、评价参数、负载、被控对象、采样设置和其他环境。采样参考间隔是各自数据属性，不因间隔不同假装评价阈值相同或重采样；比较参数时区别该属性与用户评价参数。控制器参数作为实验条件记录，不要求相同。

物理量/单位或目标/归一化初值、评价口径不一致时，显示各侧值与警告，拒绝不具共同意义的差值/百分比，不做隐式单位换算。单位或物理量不同不在同一物理纵轴叠图。条件未知或不一致时，只做带警告的描述性对比；即使记录一致也不自动将差异归因于PID修改。

显示四项跟踪指标和三项响应指标。差值=`B-A`，变化百分比=`100*(B-A)/abs(A)`；这是有符号数值变化，不是“提升分”。A为0、任一指标不可用、口径不一致或运算溢出时百分比为空并给原因，不能编造0。正负末段偏差不能仅凭其有符号差认定更优。
