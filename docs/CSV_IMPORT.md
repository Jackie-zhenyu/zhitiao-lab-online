# CSV 导入规则（第二阶段）

`core.parser.parse_csv` 是上传文件和示例的统一入口，接收原始字节或二进制文件流。默认上限为 20 MiB（20 × 1024 × 1024 字节）和 200000 条数据记录，表头不计入行数。`ParserOptions` 可配置上限。

二进制流按不超过 64 KiB 的块读取，总量最多为配置上限加 1 字节；额外 1 字节仅用于识别超限。已提供的字节先检查长度，再解码。CSV 逐记录检查行数，在第 N+1 条记录立即拒绝，不先建立超限 DataFrame。原始输入仍受字节上限约束；这不是无限流解析器。

## 编码与分隔符

- 自动编码只接受严格 UTF-8 / UTF-8 BOM，不猜测其他编码、不替换坏字节。可手选 UTF-8、UTF-8 BOM、GB18030、UTF-16、Windows-1252。保留原字节，记录实际解码编码。
- 分隔符支持逗号、分号、制表符。自动识别检查第一条完整 CSV 记录（含带引号的多行表头），只有一种分隔符解释为多列表头时采用；无候选或多候选均要求手选。它有意保守，不用后续数据偷偷替用户猜测。
- 标准 CSV 引号和转义由 Python `csv.reader` 解析，字段内换行保留。单字段长度遵循 Python 当前 `csv.field_size_limit()`；本模块不修改进程共享的默认值。超长字段明确报错。
- 空文件、只含表头、空列名、重复列名、空数据记录、列数不齐、非法引号均报错。不会跳过空行或坏行。表头和字段不自动去除空格。

## 来源与后续处理

返回对象保留原始字节、完整 SHA-256、原始文件名、字符串 DataFrame、每条记录起始物理行号，以及格式解码记录。同名不同内容产生不同内容摘要；同内容不同文件名摘要相同。SHA-256 仅标识内容，不证明实验真实性。

解析层不把字符串转成数值，不排序、删行、填补、平滑或插值。空字符串、NaN、无穷字符串和非数值原样交给后续质量检查。`recommend_mapping` 只推荐无歧义的中英文列名别名；字段是否齐备、单位是否一致由后续显式映射确认校验。即使列名为 `time_ms`，也不自动确认时间单位；更不推断编码器分辨率或脉冲转换比例。

DataFrame 的第 0 行对应第 1 条数据记录；`source_lines` 给出其在 CSV 中的起始物理行，用于定位多行引号字段之后的问题。
