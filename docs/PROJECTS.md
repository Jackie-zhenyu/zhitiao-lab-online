# 本地项目包 · 第八阶段

项目包解决关机或新会话后继续实验的问题。它是用户显式下载、再上传恢复的 `.labproj` 文件；没有自动保存、数据库或服务器路径选择。它包含完整原始 CSV，**未加密**，请按实验资料保管。`.gitignore` 排除项目包，Docker 构建上下文也不包含这些文件。

## 使用

1. 在实验分析页加载或上传 CSV，确认字段、单位、区间和需要的阶跃；需要比较时分别保存实验快照。
2. 展开左侧底部“项目 · 保存与恢复”，填写名称和备注，点击“生成项目包（含原始 CSV）”，再点击“下载项目包 .labproj”。仅生成按钮不会将文件自动保存到电脑。
3. 关机、刷新为新会话或重启后，选择此前下载的包，点击“校验项目包”。核对项目名称、实验和快照数量，勾选替换声明，再点击“恢复项目（替换当前会话）”。失败时原实验不被替换。
4. 恢复后工作实验显示在“上传 CSV”入口，沿用原字段、单位、质量规则、分析区间、初值、指标与异常阈值。已确认阶跃用“手动指定”展示，保留原基线或手工初值来源，不再次猜测阶跃。
5. 历史快照可载入为工作实验或从历史列表移除。载入保留原快照；移除会撤销当前 A/B 结果。修改工作实验不会改写原快照。
6. 项目生成后再改文件、单位、区间、参数或备注，旧下载仍是冻结包，并显示页面已变化。需要重新生成和下载才能保存最新内容。
7. 勾选并点击“清空当前会话”，删除该会话内的实验、快照、聊天和导出缓冲。其他会话、原始磁盘文件和已下载文件不受影响。

## 保存边界

包含当前已成功解析的原始文件（也可尚未确认字段）、最多8份独立确认快照、确认配置、质量和指标结果、异常规则、已计算的A/B结果、项目名称及备注。原始字节按SHA-256去重，不改写；映射顺序和转换记录保留。

未成功解析的当前文件会阻止保存，避免悄悄漏掉用户的数据。区间与参数以实际已生成的指标记录为准。未确认的页面草稿、无有效结果的区间草稿、图表显示点数与临时聚焦、文件选择器状态、密钥、会话身份、AI发送授权、活动聊天及工具证据不保存。恢复后已有AI引用不能用于新会话；使用AI必须重新选择、授权并执行工具。

如果生成过报告，保留当时报告的原JSON作为**历史归档**。导入时仅校验其摘要、结构和支持的版本；归档不是重新计算的事实证明，不恢复为活动AI证据，也不直接生成HTML。页面仅提供历史JSON下载。新HTML、JSON、指标CSV报告须在“报告预览”通过现有核验接口重新生成。恢复后未调用AI的新报告标注AI未参与。

SHA-256验证完整性，不是数字签名，不能认证作者、来源真实性、设备条件或人工初值。程序拒绝已配置凭据和常见`sk-`格式出现在包中；它不能识别所有未知秘密，请勿将凭据放在CSV、文件名或备注中。检测到凭据会整体拒绝，不能在改动原始字节后还声称原文件不变。

## 文件格式与限制

版本 `lab-project-v8.0`，只接受本程序生成的无压缩 ZIP（ZIP_STORED），不使用 pickle，不执行包内代码，不解压到磁盘。允许的成员只有：

```text
manifest.json           项目信息、解析与确认配置、结果、算法版本、原始摘要引用
blobs/<sha256>.csv       精确原始字节，按摘要去重
report.json             可选的历史报告 JSON
```

禁止未知成员、重复成员、路径穿越、链接、压缩/加密、ZIP64、注释、隐藏字节和不一致目录；在创建ZIP成员对象前检查中央目录大小与数量。JSON拒绝重复键、NaN/Infinity、非有限数字和过深嵌套。元数据采用白名单，不从包中接受会话身份或可执行指令。

| 本机限制 | 当前值 |
| --- | --- |
| 项目包 | 128 MiB |
| 去重原始 CSV 总量 | 64 MiB |
| 每份 CSV | 20 MiB / 200000 数据行 |
| 已保存实验快照 | 8份，另外可有1份当前工作实验 |
| manifest.json | 16 MiB |
| 历史 report.json | 32 MiB |
| JSON嵌套深度 | 48层 |

上述界限在 `projects/archive.py` 中明确设置；包内不能自行放宽。CSV页可以采用更高导入上限，但本版项目包会拒绝超出项目保存限制的配置。数据较大、质量问题过多导致manifest超限时，保管原CSV并分项目保存，不静默截断。当前控件不能原样表示的参数也会拒绝恢复，不自动修改参数。

## 恢复核验与兼容性

核对格式和所有算法版本、成员摘要与原始字节，按记录的编码、分隔符及限制调用原CSV解析器，重新准备映射、执行质量检查、指标与异常规则，再调用原A/B接口。记录结果必须与重算一致，才构造独立的新会话并整体替换。没有修改 `core/` 的算法或 `docs/METRICS.md` 的数值定义。

当前只支持相同项目格式及算法版本，不提供旧版自动迁移或任意外部项目兼容。算法升级前请保留原版本、CSV与下载报告。项目包可跨应用重启恢复；跨不同依赖版本或平台的浮点结果若不完全一致会拒绝恢复，不能通过放宽校验强行导入。

相关自动测试位于 `test_project_archive.py`、`test_project_security.py`、`test_project_session.py`、`test_project_ui.py`。实际计数及浏览器验证见 [ACCEPTANCE.md](ACCEPTANCE.md)，阶段进度见 [PROGRESS.md](PROGRESS.md)。
