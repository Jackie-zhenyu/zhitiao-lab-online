# 异常现象证据规则 · 第四阶段

规则只检测现象，不诊断根因，不更改第三阶段METRICS定义。所有默认阈值在界面展示并可修改；结果保留配置，区分默认值与用户值。未发现规则事件不等于系统完全正常。

## 连续性与时间

动态规则仅在质量报告中每个连续有效片段内执行，不跨断点排序、补值或平滑。区间定位保留原始行及秒时间；持续时间按原始首尾时间差计算。时间占比采用左端样本状态在下一相邻采样区间内保持的约定：`sum(flag[i]*dt[i])/sum(dt)`，明确是采样状态的时间估计，不用样本数量占比代替。

## 规则

1. **稳定目标附近持续波动**：默认2秒观察窗口内，目标相对中位数偏差≤1e-6物理单位；误差时间均值绝对值≤0.2单位，实测峰峰差≥0.05单位，误差越过±0.01死区后交替符号至少4次，死区外时间占比≥25%。窗口按半个请求窗长移动，起点取下一个原始样本，终点取首个达到“起点+请求窗长”的样本；实际跨度至少为请求窗长且最多多一个采样间隔，并记录该跨度。没有完整窗口时报告数据不足。仅合并同一有效片段内重叠的命中窗口，重算合并区间观测量并记录窗口数，不能跨无效行。记录峰峰差、交替次数、平均偏差（实际时间梯形均值）和死区外时间占比（左端状态乘dt）。此现象不能确认PID不当、机械共振、噪声或不稳定性。
2. **控制输出持续接近用户限幅**：必须有control及用户确认的上下限。接近带默认为上下限跨度的2%，要求与某一限值的绝对距离在该带内，连续样本首尾跨度≥0.5s。分别记录接近上限/下限、实际极值和持续时长。只称输出持续接近限值；即使存在i_term也不据此确认积分饱和，更不判断具体抗饱和算法是否有效。
3. **测量变化**：确认合理物理变化率上限时，对相邻有效点计算abs(Δactual)/Δt，超过上限标为变化率规则命中。未确认上限时仅给“统计突变候选”：每片段至少3个相邻变化率样本（4个原始点），默认绝对变化率超过中位数+6×1.4826×MAD且绝对跳变量≥0.05单位。MAD为0时仍需超过中位数及绝对跳变下限。每个命中的相邻点对保存独立事件，记录Δt、跳变量、变化率及统计阈值；不称传感器故障，不擅自把真实快速动态视为错误。
4. **数据记录异常**：将已有质量问题转成证据卡，保留规则、数据行、CSV物理位置和原始问题说明。缺失/倒退/重置导致时间无法可靠定位时，起止时间均为空并说明原因，改用原始行聚焦，不编造时间。

事件包括event_id、experiment_id、起止时间/原始行、规则、阈值、观测量、关联图表、现象、未确定原因和限制。ID由来源、规则配置和原始定位生成，内容/规则改变不得沿用失效事件。点击卡片只聚焦图表或原始行，不改变计算区间、原始数据或性能指标。
