# 运行与部署边界

默认交付为本地单进程 Streamlit，已验证 Windows x64 / Python 3.12.14。启动器固定监听 `127.0.0.1`；不自动开放公网、修改防火墙、购买服务或推送远程。无需配置模型即可分析与导出。

## 可选 Docker

已提供 `Dockerfile` 与默认排除的 `.dockerignore`，使用官方 Python 3.12.14 slim-bookworm 标签、项目虚拟环境、锁定依赖、非root用户与健康检查。构建上下文只包含应用和明确列出的公开示例，不包含`.env`、私人数据、缓存、输出或本机虚拟环境。

**本机没有 Docker CLI，因此未执行 docker build 或 docker run，容器运行尚未验证。** 官方镜像标签核对和Linux wheel解析不能替代容器验收。具备Docker的机器可自行执行：

```bash
docker build -t zhitao-lab:local .
docker run --rm --name zhitao-lab -p 127.0.0.1:8501:8501 --memory=2g --cpus=2 --pids-limit=128 zhitao-lab:local
```

内存/CPU数字只是本地试运行上限示例，未经过负载定容；大型日志或多份快照可能触及限制并退出。容器内部监听0.0.0.0由端口映射限制在宿主本机。不要省略映射中的`127.0.0.1`，不要直接将端口暴露公网。容器停止后会话内实验和未下载报告消失；第八阶段支持显式下载项目包，下次上传重算核验后恢复，仍无自动磁盘保存。Dockerfile包含projects模块，但容器运行仍未验证。

本地无AI无需`--env-file`。可选AI在运行时通过本机未跟踪的专用环境文件或服务器秘密注入机制提供四项LLM变量，不复制进镜像、不在Dockerfile写密钥；更改配置后重建会话/重启进程。不要把真实密钥写入命令行历史、构建参数或Git。模型配置见 [LLM_CONFIGURATION.md](LLM_CONFIGURATION.md)。

## 公开演示需另行准备

这不是本阶段已经完成的公网部署。若今后决定开放，至少还需要：

- 在反向代理/身份网关配置访问控制、TLS和WebSocket支持；应用本身没有用户登录与权限管理系统。
- 为并发会话、上传大小/行数、请求频率、进程内存/CPU、报告大小和模型费用设置并实测上限。现有20MiB/200000行默认只是单文件限制，不能代表整体抗滥用能力。
- 服务端注入模型密钥；限制出站目标，禁止记录完整请求/实验日志，评估供应商数据处理要求。保留应用每轮摘要授权，不用网关登录替代用户发送授权。
- 明确会话回收、重启丢失、下载保管和隐私政策；评估多人负载、会话隔离、代理超时和升级回滚。这些压力/运维验证尚未完成。

Linux/macOS实机运行也尚未验收；Windows上的Linux CPython3.12 wheel解析可获取性检查通过，仅说明依赖解析情况。镜像基础标签未按digest固定、依赖未附wheel哈希：版本已固定，仍需在正式发布时按目标平台构建、审查并保存不可变产物。
