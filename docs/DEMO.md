# 智调 Lab · 约三分钟演示

演示前启动 `scripts/start.cmd` 并打开 `http://127.0.0.1:8501`。首次安装不计入演示时间；安装包准备好后，本地流程无需网络或模型密钥。导航仍是“实验分析 / 实验对比 / 报告预览”，AI 在独立标签。

## 路径与讲解

| 时间 | 操作 | 展示与说明 |
| --- | --- | --- |
| 0:00–0:25 | 实验分析→加载示例→闭环 PI A→一键加载示例 | 明确“闭环仿真数据，非实测”。这是同对象 PI 控制的数值记录，不是真实设备。字段推荐仍需确认。 |
| 0:25–0:55 | 核对 time/target/actual/control/p_term/i_term、时间 s、物理量“响应量”、单位均为1；勾选单位一致并确认 | 1051行、0–21s，质量结果、三组交互曲线和时间加权跟踪指标；未排序、填补或平滑。 |
| 0:55–1:20 | 核对候选 t0=1s、0→1、阶跃前基线 y0=0，勾选并计算；展开保存区，以“PI A”保存 | 七项指标由程序计算；响应采用相对于目标值归一化，不是标准stepinfo稳态值口径。保存的是会话内确认快照。 |
| 1:20–1:50 | 加载闭环 PI B，重复核对字段、单位、阶跃与基线，以“PI B”保存 | 两份示例只改变PI参数，共用对象、采样、初值、目标、噪声和限幅。不要把结果差异自动归因于真实设备PID修改。 |
| 1:50–2:15 | 实验对比→选择A/B→核对条件→确认共同20s→计算 | 按t−t0对齐；各侧原时间戳计算。看上升、超调、RMSE和末段偏差；超调A=0时百分比不可用。改窗口后旧结果撤销。 |
| 2:15–2:40 | 报告预览→已确认A/B对比及两侧实验→生成快照→下载HTML/JSON/CSV | 核对配置、区间、结果ID与页面一致。HTML内嵌Plotly，可交互；无AI时标注“AI未参与”。 |
| 2:40–3:00 | 返回实验分析→加载“数据质量问题”并确认→异常证据→聚焦一条记录问题 | 展示行号和检测依据，区分现象与未知原因。切换顶部AI区域，未配置时明确“AI未配置”，本地成果完整保留。 |

操作熟悉程度和机器速度会影响总时长。为了演示更从容，可在开始前保存两份PI快照，现场保留A的确认过程并直接切换A/B。

## 示例来源

- “一阶解析阶跃响应”“非等间隔采样”“数据质量问题”：**解析函数合成数据，非实测**，不是实际闭环仿真；公式及生成命令见 [examples/README.md](../examples/README.md)。
- “闭环 PI A/B”：**闭环仿真数据，非实测**；方程、离散更新顺序、PI参数、无噪声规则和种子见 [examples/CLOSED_LOOP.md](../examples/CLOSED_LOOP.md)。数据没有手工修饰。
- 也可下载示例再从“上传CSV”上传；此时需要自行填写和确认物理量/单位。文件导入与一键加载调用同一解析流程。

## 可选真实 AI 演示（另计时间）

仅在本地已填写有效配置且愿意发送摘要时进行。选AI区域，输入“分析实验A”，核对将发送的摘要并授权；随后追问“只看其中2～5秒”，再次授权，展开记录验证产生新的工具调用及区间。切换A/B可问“与实验B比较超调和响应时间”。无配置时展示“AI未配置”；已配置但无网络或未授权时跳过云端调用，说明对应限制并展示本地报告。不要放入测试替身回复冒充在线结果。真实接口联调当前尚未验证。

完整异常边界与导出断网重开步骤见 [ACCEPTANCE.md](ACCEPTANCE.md)。

## 第八阶段续接演示（约1分钟，另计）

完成A/B报告后，展开侧栏底部“项目 · 保存与恢复”，命名并生成、下载项目包。显式清空当前会话，展示空白分析页；选择下载的同一包，校验并恢复。应重新出现原始来源、单位、阶跃指标和两份历史快照，对比页保留原共同窗口。新会话的AI授权与活动聊天为空，历史报告只提供JSON归档。修改一个阈值后再次生成和下载，说明旧包不会自动更新。重启后也可用相同步骤恢复，详细格式和限制见 [PROJECTS.md](PROJECTS.md)。
