# 智调 Lab 需求

## 定位与完整流程

面向大学生控制实验、电机调试和机器人实验的日志分析 Agent。

最终流程：上传 CSV → 确认字段和单位 → 查看曲线与性能指标 → 定位异常区间 → 对比两次实验 → 通过 AI 追问分析 → 导出可追溯报告。

## 第一阶段（已完成的历史范围）

只完成项目初始化、可启动的中文 Streamlit 网页骨架、Pydantic 数据契约、基础测试和开发文档。不需要 API Key。

- “实验分析”“实验对比”“报告预览”三个入口。
- 简洁清晰的实验工作台；未实现功能明确显示“尚未实现”。
- 不展示虚假曲线、数值、实验记录或 AI 分析。上传控件和后续操作保持禁用，并说明原因。
- 建立 core、ui、agent、reports、examples、tests、docs 边界，空模块只说明职责，禁止返回虚假成功结果。
- 实际安装依赖、执行 pytest、启动本地服务并记录验收。

## 技术与边界

- Python 3.11 或兼容的已安装版本；本次选用 Python 3.12.14，独立 `.venv`。
- Streamlit 单体应用；pandas、NumPy、SciPy 负责后续数据分析，Plotly 负责后续曲线，Pydantic 校验输入输出，pytest 测试。
- 核心逻辑不依赖UI或模型。前四阶段不调用模型；第五阶段通过独立agent模块实现可选模型适配、受限工具和执行流程。
- 不引入 React、FastAPI、LangChain、向量数据库、用户登录、实时串口控制、自动下发 PID 或模型训练。
- 不修改系统级 Python 环境；不推送远程、不部署公网。

## 数据契约

必要结构：Experiment、AnalysisConfig、MetricResult、EventResult、AnalysisResult，可增加少量共享结构。

结果应携带或通过结果容器保留：实验 ID、分析区间、数值及单位、状态和原因、配置、数据来源标识、算法版本。分析区间采用秒且起点不得晚于终点；来源区分实测、仿真和未知。保留原始字段与单位、处理规则和来源指纹的表达能力。

无法计算时数值为 `None`，返回明确状态及原因；成功结果必须有有限数值与明确单位。禁止使用 0 代替缺失或失败。输入未知字段应报错，来源和结果实验 ID 应保持一致。算法版本只表示数据契约/算法标识，不宣称已实现分析。

## 第一阶段的后续范围（历史记录）

CSV 解析、字段映射与单位确认、数据质量检查、曲线、性能指标、异常检测、实验对比、AI 问答、报告导出、仿真示例生成。后续顺序需按下一次任务确认，不在本阶段提前开发。

## 验收要求

1. 不配置模型即可从 README 命令启动。
2. 三个入口可以切换，所有后续能力明确显示尚未实现。
3. pytest 验证数据契约关键边界和页面启动/切换；不调用网络或模型。
4. 记录实际 Python、依赖版本、安装结果、测试结果、启动命令与局限。
5. 原始文件只读、处理可追溯、仿真显式标注、秘密不入库。

## 第二阶段（已完成的历史范围）

本次用户已授权实现 CSV 导入、字段映射、数据质量检查、基础曲线及可重复生成的解析函数合成示例。第一阶段“禁用上传”等要求只表示历史状态。

- 编码：自动严格尝试 UTF-8/BOM，可手动选择编码；分隔符支持逗号、分号、制表符，自动识别不可靠时要求手选。
- 导入上限默认 20 MiB / 200000 数据行，可配置；字节读取和逐行解析过程中落实上限。保留原始字节与 SHA-256。
- 必需映射 time/target/actual，可选 control/p_term/i_term/d_term；推荐必须由用户确认。时间 s/ms 转为 s；物理量和单位由用户填写并确认目标/实测一致，不猜编码器比例。
- 检查缺失、非数值、无穷、重复时间、倒退、疑似重置、采样间隔异常；报告位置和统计。规则可配置，不把规则命中等同于设备故障。
- 不自动排序、删除、填补、平滑、插值。阻断问题阻止整段绘图，允许用户明确选择原始行连续且时间单调的有效区间；不能跨越缺失或异常间隔。
- 实验与中间结果仅在 Streamlit 会话内保存；内容摘要识别同名变化；导入、映射、单位或检查配置变化使旧确认/结果失效。
- Plotly 显示目标/实测、误差 target-actual、可选 control；单位和实际行/时间区间明确；降采样仅影响显示。
- 三个示例标注“解析函数合成数据”，提供下载与加载，走统一解析和确认流程。不是实测，也不声称真实闭环仿真。
- 不接 AI，不做复杂控制指标、实验对比或报告生成。更新测试、README、PROGRESS 并实际验收。

## 第三阶段（已完成的历史范围）

已授权控制性能指标、分段选择、程序化结果解释和独立数值验收。先更新既有 `METRICS.md` 的占位定义，再编码；不接 AI。

- 一般跟踪：基于实际时间积分的 RMSE_t、IAE、采样最大绝对误差和末段时间平均偏差；不将后者称为稳态误差。
- 响应：明确“相对于目标值的归一化约定”，不冒充按实测稳态归一化的标准 stepinfo。支持正负阶跃、用户确认的候选/手动区间、基线或手动 y0。
- 上升阈值、目标带和观察时长按 `METRICS.md` 实现，逐指标返回成功、不适用、观测内未达到、数据不足或数据异常。
- 页面卡片、表格、逐项定义和追溯记录、曲线标记；配置或选段变化撤销旧阶跃确认。
- 独立一阶解析基准 ln(9)、-ln(0.02)、0% 验收；涵盖非等间隔、负阶跃、非零初值、短记录、波动、未达和断点。
- 报告生成、实验对比、AI、设备控制仍未实现。完整指标容器与报告占位说明保留归一化声明，供后续报告使用。

## 第四阶段（已完成的历史范围）

在不改变第三阶段指标口径、不接入AI的前提下，实现异常现象证据和A/B实验对比。

- 可配置规则检测稳定目标附近持续波动、输出持续接近用户确认限值、测量突变/变化率和数据记录异常；阈值及默认/用户来源可见。
- 事件保留ID、实验、起止时间/原始行、规则、阈值、观测量、关联图表、限制、检测到的现象与未确定原因。卡片聚焦不改变原始数据或分析区间。
- 无control或未确认限值不判断输出近限；不确认积分饱和；无物理变化率上限时仅统计候选，不认定传感器故障。无事件不等于系统正常。
- 会话内保存独立确认快照；各自选定单阶跃，按t−t0对齐，用户确认共同请求观察时长，各侧原始时间戳分别计算，展示实际采样边界。
- 可比性检查物理量、单位、目标/初值、评价参数和对象/负载/采样/环境条件；未知/不一致警告，仅描述差异，不自动归因PID、不评分或宣称绝对优胜。
- 同对象、初值、目标、采样、限幅、噪声等条件的PI A/B闭环仿真，只变PI参数，保存方程、更新顺序、参数、种子与摘要，明确“闭环仿真数据，非实测”。
- 验收事件区间、限幅缺失、时间权重、负阶跃、窗口、单位、零分母及自比零差异，并运行既有测试。具体规则见EVIDENCE、COMPARISON及闭环示例文档。
