# 控制性能指标定义 · 第三阶段

本文件在第三阶段数值实现之前确定计算约定，算法版本 `control-metrics-v3.0`。使用原始有效采样数据，不接入 AI，不自动清洗、排序、平滑或跨断点插值。

**响应指标采用“相对于目标值的归一化约定”。不是按实测稳态值归一化的标准 stepinfo 结果。** 页面、结果容器和报告必须保留此声明；第六阶段已实现报告导出，格式见 [REPORT_FORMAT.md](REPORT_FORMAT.md)。本阶段仅更新此能力说明，以下指标定义保持不变。

## 区间与时间积分

先通过质量检查，再明确选取至少两个采样点的连续原始行闭区间 `[ta,tb]`，`tb>ta`。时间为秒，目标和实测已确认同一单位 U。非有限值、时间非递增、原始行不连续或违反已确认间隔规则均返回 `invalid_data`；不足两点返回 `insufficient_data`。不存在有效时间跨度时不计算。

所有积分采用实际时间戳的复合梯形公式 `sum((f[i]+f[i+1])/2 * (t[i+1]-t[i]))`，支持非等间隔采样；不是普通样本均值。对误差平方和绝对误差分别构造被积样本后应用梯形公式，数值积分本身有离散误差，不声称积分了未知的真实连续响应。计算使用全量选段，绘图抽点不影响指标。

| 指标（结果键） | 定义 | 单位 |
| --- | --- | --- |
| 时间加权 RMSE (`rmse_t`) | `e=target-actual`；`sqrt(∫e²dt/(tb-ta))` | U |
| IAE (`iae`) | `∫abs(e)dt` | U·s |
| 最大绝对误差 (`max_abs_error`) | 选段内采样点的 `max(abs(e))`，不推断采样之间峰值 | U |
| 末段平均偏差 (`tail_bias`) | 默认末尾 10% **时间跨度** `[tb-0.1*(tb-ta),tb]` 上的 `∫e dt/窗口时长`；正值表示实测低于目标 | U |

末段比例可配置 `(0,1]`。窗口起点落在相邻有效样本间时仅为积分边界线性计算 e，不改变原始数据；禁止跨质量断点。记录准确窗口及积分方法。没有稳定性证据，绝不将末段平均偏差称为“稳态误差”。

## 单次阶跃识别、确认和初值

自动识别只推荐分段常值目标中的离散跳变，跳变量须大于 `amplitude_epsilon`，前后目标平台至少各两个采样点，相对各自中位数偏差不大于 `target_flat_tolerance`。为避免将容差内抖动误识别为阶跃，相邻候选边界还须大于 `max(amplitude_epsilon, 2*target_flat_tolerance)`；难与容差区分的小阶跃保守不推荐。持续斜坡/抖动无法得到可靠平台时不给出可靠候选；多个候选各有独立观察终点（下一次跳变前的最后采样点），不能混为一阶跃。

候选 `t0` 为新目标平台第一个采样点，真实触发可能位于它与上一点之间，页面提示这一采样分辨率局限。用户须核对并点击确认；可手动指定 t0、r0/r1 和观察截止数据行。手动 t0 必须位于选段时间范围内，不外推，只有一个目标转变；阶跃后全部目标应在 r1 的平台容差内，前基线目标在 r0 容差内。不以手动模式绕过质量或平台检查。

`y0` 从 `[max(ta,t0-baseline_window_s),t0)` 的有效阶跃前样本估计：默认窗口 0.5 s，至少 3 点且时间跨度至少 0.1 s；目标须为 r0 平台，实测峰峰差不得超过 `baseline_range_tolerance`（默认 0.02 U）。采用该基线实际首尾样本间的时间加权均值，不延伸到阶跃之后。记录样本行、实际基线区间和估计方法。无基线、基线不足或不平稳时须用户明确填写有限 y0，标注“用户提供”，不默认用零。基线只在当前连续选段内取样，不跨先前阶跃。

记录 t0、r0/r1、y0、y0 来源、基线区间、阶跃区间、目标单位、参数及用户确认。若 `abs(r1-r0)<=amplitude_epsilon` 或 `abs(r1-y0)<=amplitude_epsilon`，响应指标为 `not_applicable`。绝对幅值容差默认 `1e-9 U`，用户应按信号尺度调整。

## 相对于目标值归一化的响应指标

令 `D=r1-y0`、`A=abs(D)`、`q(t)=(actual(t)-y0)/D`。D 可为负，正向和负向阶跃使用同一公式。观察区间 `[t0,tend]` 内不从记录尾端估计响应终值。若 t0 在采样点之间，仅在包围它的相邻有效实测样本间线性求值，以限定观测起点。

| 指标（结果键） | 定义 | 单位 |
| --- | --- | --- |
| 目标归一化上升时间 (`rise_time`) | q 从下方首次达到 lower=0.1 的时刻 t10，到随后首次达到 upper=0.9 的 t90 的差；阈值可配置 `0<lower<upper<1` | s |
| 目标归一化超调量 (`overshoot_pct`) | `max(0,max(q)-1)*100`，使用观测样本及 t0 边界值；无超调时真实结果为 0 | % |
| 目标调节时间 (`settling_time`) | 从 t0 到最终连续处于目标误差带的区间起点 ts，即 `ts-t0`；必须还满足 `tend-ts>=min_observation_s` | s |

上升阈值交点仅在相邻有效采样点之间线性插值，不跨断点、不使用高阶拟合。若观测起点 q 已超过低阈值，缺少第一次交点证据，返回 `insufficient_data`，而非假设从 0 s 开始。已观察到低阈值但没有达到高阈值，或始终低于低阈值，返回 `not_reached`；不借后续阶跃补足交点。

目标误差带为 `abs(actual-r1)<=max(relative_band*A, absolute_tolerance)`，默认 `relative_band=0.02`、`absolute_tolerance=0 U`。界线计入带内。ts 是最后一次带外样本之后到下一个带内样本的线性边界交点；若从 t0 起全部在带内，则 ts=t0。此定义依赖采样之间线性变化的数值假设，不能排除未采到的带外波动。只要末尾仍在带外，即观测内未达到；最终进入后留存时长短于默认 0.5 s（可配置）则为数据不足。返回 ts、实际后续观察时长、所需观察时长和带宽。

**调节时间只表述为“在本次观测区间内满足”。不保证未来不再离开，不宣称稳定性或收敛证明。** 短记录可能使超调已有数值但上升/调节仍无法计算，各指标分别给状态。

## 返回状态与追溯

- `success`：有限数值（包括真实的 0），记录定义、原因/解释、单位和区间。
- `not_applicable`：静态目标、近零阶跃/归一化幅值、非单次阶跃或目标持续变化。
- `not_reached`：观测内未达到阈值或没有保持在目标误差带。
- `insufficient_data`：采样/基线/交点证据不足、观测过短或后续留存不足。
- `invalid_data`：断点、非有限值、时间异常或数值溢出。

非成功值必须为 `None`，配明确原因；不能用 0、NaN 文本或无限大代替。结果保存实验 ID、原始 SHA-256/来源声明、映射和单位、原始行区间、质量规则、全部指标参数、基线与手工输入、交点及观察时长、算法版本和归一化声明。改动源数据、映射、选段或配置后不复用旧指标或阶跃确认。未来报告必须复用这一完整容器和声明。

## 独立数值验收与局限

解析基准 `y=1-exp(-(t-t0))`，阶跃前 y0=0、目标由 0 到 1：上升时间 `ln(9)`，目标调节时间 `-ln(0.02)`，超调 0。理论常量直接由数学公式给出，不能调用被测函数构造期望；交点线性插值误差按实际最大采样间隔限制（平滑一阶响应可用 O(h²) 界）。同时验证负阶跃、非零初值、静态目标、未达目标、持续波动、非等间隔、短记录、断点和已知积分案例。

不能可靠自动解释：缓慢斜坡、多次阶跃混在同一观察段、噪声平台、基线漂移、触发发生在记录之前、严重欠采样、样本之间未捕获的峰值/离带、质量规则未识别的数据丢失。允许在证据充分的连续区间内明确手动输入；不把输入替代成实验事实，不自动扩大容差以获取成功结果。
