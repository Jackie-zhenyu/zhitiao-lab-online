- 指标相对于目标归一化，不是按实测稳态值归一化的标准 stepinfo。异常规则只检测现象；无事件不证明完全正常，不确认 PID 根因或向设备下发参数。商业模式写为待验证方案，不编造收入、客户或落地效果。

## 数据来源、安全与保存

使用五份公开示例：一阶解析响应、非等间隔采样、质量问题为“解析函数合成数据”；PI A/B 为“闭环仿真数据，非实测”，由同一对象与环境、不同 PI 参数真实计算生成，不人工改曲线。软件指标引用本次程序结果；截图和字幕不能把示例包装成实测。

公开源码 ZIP 由精确文件名白名单生成，五份 CSV 逐项核对固定 SHA-256。排除密钥、真实 `.env`、虚拟环境、私人实验、`.labproj`、日志、缓存、work/outputs 和 PDF/MP4成品。检查已配置凭据但不打印其值，原文件只读，默认不覆盖已生成文件；包内外提供摘要清单。完整说明见 [RUNNABLE_SUBMISSION](RUNNABLE_SUBMISSION.md)。

私人实验保留在本地会话，关闭前须主动下载项目包。项目包未加密，包含原始 CSV，不随公开源码提交；恢复不继承 AI 活动身份、聊天证据与授权。

## 制作环境与运行环境

应用运行使用项目 `.venv`、Python 3.12 和 `requirements.lock.txt`；本机实际验证为 Windows x64 / Python 3.12.14。Windows 运行 `scripts\install.cmd`、`scripts\start.cmd`；Linux/macOS 对应命令见 [源码交付说明](RUNNABLE_SUBMISSION.md)。首次安装依赖通常需要网络，之后本地分析无需密钥或外网。

PDF/MP4 制作使用独立的 `work/submission-tools/.venv`：ReportLab 4.4.4、pypdf 6.1.1、Pillow 11.3.0、imageio-ffmpeg 0.6.0；中文配音使用本机 System.Speech 的 Huihui 语音。FFmpeg 二进制实际版本由视频制作验收记录补充。制作工具和真实界面素材不进入应用锁定依赖，不影响评委启动应用，生产 `requirements.lock.txt` 未改。

可选 `build_submission_pdf.py`、`build_submission_video.py` 是交付材料制作脚本；源码包不含录制截图、帧序列、字体、语音组件或工具二进制，重建媒体需准备对应公开素材和额外工具环境。最终文件信息以制作验收记录为准，不能据“脚本已生成”宣称视频/PDF验收完成。

不自动部署公网、不购买服务、不推送远程。Docker、Linux/macOS实机、多人压力和物理断网重开 HTML 的既有未验证边界保持不变。
