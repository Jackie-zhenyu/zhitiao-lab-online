# 报告格式与一致性

第八阶段项目包可附带原JSON报告作只读历史归档，不能恢复为当前AI证据，也不将导入JSON直接喂给HTML生成器。恢复后在报告预览重新生成新报告；项目格式与校验边界见[PROJECTS.md](PROJECTS.md)。原报告格式和数值口径保持不变。

第六阶段，格式版本 `lab-report-v6.0`。支持 HTML、JSON、指标 CSV；Word/PDF 尚未实现。数值和规则沿用 [METRICS.md](METRICS.md)、[EVIDENCE.md](EVIDENCE.md)、[COMPARISON.md](COMPARISON.md)，没有新增计算口径。

## 生成与冻结

先在实验页确认字段、单位和有效分析区间，按需确认单次阶跃；或完成已保存实验的 A/B 比较。在“报告预览”选择范围、填写名称/备注，点击“生成 / 更新报告快照”。仅有质量结果、缺失指标或无 AI 结果也可生成；尚未确认字段时不可生成。

生成器从当前会话抓取结果，用现有解析、质量、性能、事件和比较函数复核原始 SHA-256、字符串数据、映射、转换、区间、配置与计算结果的一致性。重新调用用于核验，不替换算法或覆盖页面结果。核验失败会拒绝新导出并保留旧报告。

`ReportSnapshot` 是冻结 dataclass，持有规范 JSON 字符串和其 UTF-8 字节的 SHA-256；`data()` 检查摘要后返回独立副本。`ExportBundle` 同时冻结 HTML、JSON、CSV，三个下载按钮使用同一份对象。修改页面配置、导入其他文件或编辑报告备注不会自动改写它；页面显示旧快照警告，须明确重新生成。重新生成有新的报告 ID 和 UTC 时间。

报告只在当前会话内保存；刷新成为新会话或服务重启后须重新生成。已下载文件是独立快照，不受页面影响。SHA-256用于核对内容，没有数字签名或第三方真实性鉴定。

## JSON 结构

JSON 为 UTF-8，数值保持程序精度；不可用值为 `null`，另含状态和原因，不使用 NaN/Infinity，也不以0代替。结构超过32 MiB时明确拒绝，不静默删掉问题或事件；可缩小报告范围。

| 字段 | 内容 |
| --- | --- |
| schema_version / report_id / created_at | 格式版本、随机报告身份、UTC生成时间 |
| project / notes / normalization | 项目与文本备注、既有目标归一化声明 |
| runs | 实验名称/ID、来源分类和声明、摘要、映射/单位、解析编码/分隔符、转换记录、条件、质量、性能、事件、图表和显示规则 |
| runs[].result_id / configuration_id | 根据计算上下文生成的结果身份与配置摘要；完整配置仍保存在对应容器 |
| comparison / comparison_charts | 可空的完整A/B计算结果，包括共同请求窗口、各侧实际区间、条件/限制、差值及相对阶跃时刻的图 |
| ai | 参与状态、已核验的对话及其程序证据；缺配置或无适用证据明确AI未参与 |
| next_verification / limitations | 核对与重复验证建议，观测及因果限制 |
| privacy | 未嵌入原始CSV、文本脱敏字段计数 |

来源区分“实测数据（用户声明，未经独立鉴定）”“解析函数合成数据”“闭环仿真数据，非实测”；上传来源不明时保持未知，仿真类型不明时不补写生成方式。不会生成未知设备型号或未进行的实验记录。

A/B报告含两份已保存实验的原确认结果及共同窗口下独立重算的比较结果。二者可能使用不同区间，指标表通过“范围”和起止秒数区分，不能混用。A/B异常规则来自保存时的配置，在报告生成时调用既有规则检测；不会把工作实验的新规则配给旧快照。条件不一致、缺失限幅、不可比和零分母的状态均保留。

## HTML

“程序计算结果”与“AI 辅助解释”明确分区。指标表与页面报告核对表、CSV共用 `metric_rows` 投影；值、状态、区间和配置来自同一JSON快照。每条指标列出结果ID和配置ID，展开可看定义、原因、完整配置；实验区可展开来源、质量问题、分析容器、基线、阈值、观察时长、版本、事件ID与检测依据。

图表保留目标/实测、误差、可选control及已有响应阈值/误差带/时刻标记；A/B图按各自 `t−t0` 对齐。每条最多5000个原始点，仅显示抽点，可能遗漏尖峰，不修改全量分析数据，不跨断点插值。JSON仅含这些必要图表数组，不嵌入完整原始CSV或原始字节。

有图表时内嵌一次当前已安装 Plotly 的完整脚本，另有初始化脚本；无图表不嵌入脚本。没有CDN、外部字体或样式依赖，可保存HTML到本机查看。CSP默认禁止资源与网络连接，仅允许具有内容哈希的两个内联脚本及必要本地样式、data/blob图像。

所有文件名、名称、备注、单位、条件、问题和模型相关文字均按不可信文本处理。HTML正文转义，图表文字另转义；脚本内JSON把 `< > &` 和Unicode行分隔符编码，避免 `</script>` 提前结束脚本。模型不能插入可信HTML，不能凭自由文本填入指标。打开未参与AI的报告不会发起模型请求。

## AI证据

只收录成功、属于本会话且仍匹配报告实验、映射、指标/事件配置、确认阶跃和授权范围的记录。再次通过既有Agent结构和引用校验，拒绝越权、不存在、旧上下文或旧配置引用。未匹配的对话不填补成答案，报告说明无适用AI结果。

事实按 `result_id` 与 `metric_key/event_id` 从实际工具记录渲染；候选解释和下一步建议采用既有受控文案。AI追问可用较小子区间，该区保存自己的工具结果、条件与上下文指纹，不能冒充主表区间或A/B条件。报告不包含服务端配置、密钥、SDK异常、思维链或完整执行日志。

导出额外移除当前已填写密钥的精确文本和符合 `sk-` 常见格式的疑似凭据，并记录脱敏次数。第七阶段修复：即使服务地址或模型等配置不完整、AI仍禁用，已填写的Key也参与脱敏；只读取显式项目`.env`（最多64KiB）或优先的环境变量，环境空值覆盖文件，不搜索父目录。这不等于能识别任意未知秘密；不得把密钥写到实验备注中。原始文件摘要仍标识原文件，文本脱敏不改原文件。

## CSV与文件名

CSV为 UTF-8 BOM、逗号分隔，包含 `report_id/result_id/experiment_id/experiment_name/scope/metric_key/name/value/unit/status/reason/start_s/end_s/configuration_id/config_json/definition`。A/B差值和百分比复用已算结果；其两侧不同区间完整保存在config_json，单一start/end留空。不可用value留空，状态和原因照常导出；只有质量结果时导出表头。

不可信文本去除前导空白、BOM/NUL后若以 `= + - @` 起始，或原文本以Tab/换行起始，加前置单引号防止电子表格公式执行。数值类型不使用文本过滤，合法负数仍是负数。JSON中保留原文本，CSV的单引号是明确的导出安全处理。

下载名固定为 `zhidiao-<报告ID片段>.html/.json/.csv`，仅允许这三种扩展名，不使用用户名称拼接路径，生产导出层不写任意磁盘路径。
